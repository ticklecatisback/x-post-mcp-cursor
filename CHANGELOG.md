# Changelog

All notable changes to this plugin are documented here.

## 0.2.0 — 2026-09-09

- Added community posts, URL/reply payloads, and media attachment support.
- Added immutable threads and one-time browser-approved scheduling.
- Added owner post analytics and schedule status.
- Added MCP refresh-token rotation, concurrent-user isolation tests, and restart recovery.
- Corrected `made_with_ai` so it describes AI-generated media rather than ordinary text.

## 0.1.0 — 2026-09-08

- Added the Cursor plugin manifest and hosted MCP configuration.
- Added one-click MCP installation.
- Added prepare, browser approval, and publish workflow documentation.
- Added privacy, security, contribution, and release documentation.
- Added automated release validation.
