# Security policy

Do not put X credentials, OAuth tokens, encryption keys, private backend source, or user data in
this repository or in a public issue.

For non-sensitive bugs, use GitHub Issues. For a vulnerability, use GitHub's **Report a
vulnerability** feature on this repository after it is enabled. If private reporting is not
available, do not disclose the details publicly; open a minimal issue asking the maintainer to
enable a private contact channel.

The supported version is the latest release. Publishing requires an exact, expiring browser
approval and the server does not automatically retry ambiguous X API responses.
