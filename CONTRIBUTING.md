# Contributing

Issues and pull requests are welcome. Keep this repository code-free and secret-free: it packages
only the Cursor manifest, remote endpoint configuration, documentation, validation script, and
artwork.

Before submitting a change:

1. Run `node scripts/validate-release.mjs`.
2. Confirm no credential, token, `.env` file, user data, or private backend source is included.
3. Document user-facing changes in `CHANGELOG.md`.
4. Keep publishing behind the existing explicit browser approval step.
